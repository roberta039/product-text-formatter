# Product Text Formatter (Streamlit)

Aplicatie Streamlit care:
- formateaza titlu + descriere + caracteristici (stil tip catalog)
- elimina diacritice romanesti
- permite copiere rapida (Copy) si descarcare .txt

## Rulare local
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Deploy gratuit
- Urca repo-ul pe GitHub
- In Streamlit Community Cloud: New app -> selectezi repo-ul -> `streamlit_app.py`
